# Arimo

Regular and bold ASCII subsets of Arimo by the Arimo Project Authors.
[Source at 903d466](https://github.com/google/fonts/tree/903d46673260c1f4c7f7ef67f5190fb03eab5042/ofl/arimo).
[License](OFL.txt).

Generated from `Arimo[wght].ttf` with FontTools 4.60.2. Instantiate weight
400 or 700 with `varLib.instancer --update-name-table`, then subset using
`pyftsubset --unicodes=U+0020-007E --name-IDs='*'`.
