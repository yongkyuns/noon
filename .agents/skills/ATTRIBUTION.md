# Skill sources and adaptation

The repository engineering skills adapt selected practices from
[Matt Pocock's skills](https://github.com/mattpocock/skills/blob/5863806dd4e15c63174bee4e7515a4256792ecfa/README.md), reviewed at commit
`5863806dd4e15c63174bee4e7515a4256792ecfa`:

- [Diagnosing bugs](https://github.com/mattpocock/skills/blob/5863806dd4e15c63174bee4e7515a4256792ecfa/skills/engineering/diagnosing-bugs/SKILL.md):
  reproduce the reported symptom, test explanations, and verify the original case.
- [Code review](https://github.com/mattpocock/skills/blob/5863806dd4e15c63174bee4e7515a4256792ecfa/skills/engineering/code-review/SKILL.md):
  assess requirements and repository conventions explicitly.
- [Domain modeling](https://github.com/mattpocock/skills/blob/5863806dd4e15c63174bee4e7515a4256792ecfa/skills/engineering/domain-modeling/SKILL.md) and
  [Design It Twice](https://github.com/mattpocock/skills/blob/5863806dd4e15c63174bee4e7515a4256792ecfa/skills/engineering/codebase-design/DESIGN-IT-TWICE.md):
  use precise terms, compare concrete interfaces, and preserve consequential decisions.
- [Retrospectives](https://github.com/mattpocock/skills/blob/5863806dd4e15c63174bee4e7515a4256792ecfa/skills/engineering/retro/SKILL.md):
  improve tools and checks after observed failures.

The adaptation uses this repository's current architecture and validation sources,
covers committed and uncommitted review scopes, and leaves routine implementation
choices with the agent. Existing repository policies and the user's requested scope
continue to govern work. The documentation skill and its examples are written for
this repository; its references identify additional writing and accessibility sources.
