User guide

Noon scenes describe objects and how they change over authored time. Python is an approachable way to explore the model; Rust can author directly against the same semantic engine.

Create a scene

Define a Scene subclass and implement construct. Create mobjects, arrange them, and use self.play for animations.

from noon import *

class Diagram(Scene):
    def construct(self):
        circle = Circle(color=BLUE)
        square = Square(color=PINK)
        square.next_to(circle, RIGHT)
        self.play(Create(circle), Create(square))
        self.wait(0.5)
        self.play(circle.animate.shift(UP), run_time=1.5)

Animation and sequencing

Calls such as Create, Transform, and .animate are familiar from Manim. Multiple animations in one play call run together; separate calls run in sequence. wait adds authored time.

Compatibility is qualified for supported behaviors, not a promise of every Manim class or option. See the implementation reference for specific behaviors.

Playback and editor

The browser editor runs source through Pyodide and Rust/WASM, with WebGPU or WebGL2 rendering depending on device support. Completed replayable scenes expose playback controls. Some input-driven, callback-driven, or incomplete sources cannot seek or replay.

Lesson navigation

Use self.next_section("Name") to mark a key point in a sequential lesson. When the resulting scene supports replay, the viewer can navigate to section timestamps.

Graphics and effects

Beyond shapes and text, current examples cover gradients, procedural shaders, images, spatial scenes, and audio. For each feature, inspect the runnable example before relying on the same API across native Python and Rust.
