API reference

The public API is evolving. This page identifies the main authoring surfaces and canonical source paths rather than presenting an unverified exhaustive generated reference.

Python authoring

SurfacePurpose
Scene, constructScene and sequential authoring entry point
Circle, Square, TextBasic geometry and text declarations
self.play(...), self.wait(...)Animation scheduling and authored time
Create, Transform, .animateCommon animation declarations
self.next_section(name)Optional lesson navigation markers

Source: web/python/noon.py and the Python example corpus. Manim compatibility and browser/native limitations are described in the implementation reference.

Rust authoring

Rust callers work directly with typed scene operations and execution sessions. Begin with noon crate source, native examples, and the Rust authoring section.

Browser and WASM

The browser shell loads an optimized noon-web WASM package and optionally Python through Pyodide. The browser playground exercises real public interfaces; it is not a separate mock engine. See web host source and web setup.

Compatibility and coverage

Support differs across native Rust, native Python, and browser Python. Native Python does not currently qualify the full browser gallery, particularly audio. Some input-driven and callback-driven scenes cannot replay. API names and packaging are subject to change.

Reference policy: before publishing a generated API listing, it should be derived from the current source and validated in CI. This curated reference does not claim exhaustive symbol coverage.
