Getting started

Start in the browser without installing anything, or run Noon locally through native Python or Rust. All three paths use shared Rust scene semantics.

Experimental: APIs, platform coverage, and packaging are changing. The current crate and PyPI names are not finalized.

Start in the browser

Open the playground, select Your first scene, and press Run. Edit the Python source and run it again. The first execution loads the WebAssembly engine and Pyodide.

from noon import *

class Demo(Scene):
    def construct(self):
        circle = Circle(color=BLUE)
        square = Square(color=PINK)
        square.next_to(circle, RIGHT)
        self.play(Create(circle), Create(square))
        self.play(circle.animate.shift(UP),
                  square.animate.rotate(PI / 4),
                  run_time=2)
        self.wait(1)

Build from source

Use CPython 3.11+ and the pinned Rust toolchain from rust-toolchain.toml.

git clone https://github.com/yongkyuns/noon.git
cd noon
python3 scripts/build-native-python.py --profile dev
PYTHONPATH=build/python python3 -m noon_native web/python/examples/ordinary_affine_play.py

Or run an existing Rust example without Python:

cargo run -p noon-native --example ordinary_affine_play
