Native Python CPython + the Rust engine

From a checkout, with CPython 3.11+ and the repository-pinned Rust toolchain. These commands use a POSIX shell.

git clone https://github.com/yongkyuns/noon.git
cd noon
python3 scripts/build-native-python.py --profile dev
PYTHONPATH=build/python python3 -m noon_native \
  web/python/examples/ordinary_affine_play.py

This builds the native extension from source. It does not use a browser. Native Python setup and current limits ↗

Native Rust No Python dependency

Clone the repository and run a native example with its pinned Rust toolchain:

git clone https://github.com/yongkyuns/noon.git
cd noon
cargo run -p noon-native --example ordinary_affine_play

About the project

A shared engine.
An evolving project.

Where it started

Noon began years ago as a minimal working prototype. It was recently redesigned with AI agents, which now contribute much of the development. It is an ongoing experiment, not a finished product.

Its relationship to Manim

Noon follows much of Manim Community Edition’s authoring semantics and visual behavior for supported features. It is not a drop-in implementation of every Manim API. Compatibility is useful, but it is not a strict long-term constraint; new features may take Noon in different directions.

What to expect today

Python works in the browser and natively; Rust has native and WebAssembly paths. Feature coverage and playback capabilities differ between hosts. Some callback-driven or interactive scenes have replay restrictions. Start with a runnable example, and consult the reference before depending on a particular feature.
