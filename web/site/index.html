Noon

Noon is an experimental, open-source animation engine written in Rust and inspired by Manim. The browser playground runs Python scenes. The repository has examples in Python and Rust that run locally.

Native Python CPython + the Rust engine

From a checkout, with CPython 3.11+ and the repository-pinned Rust toolchain. These commands use a POSIX shell.

git clone https://github.com/yongkyuns/noon.git
cd noon
python3 scripts/build-native-python.py --profile dev
PYTHONPATH=build/python python3 -m noon_native \
  web/python/examples/ordinary_affine_play.py

This builds the native extension from source. It does not use a browser. Native Python setup and current limits ↗

Native Rust No Python dependency

Clone the repository and run a native example with its pinned Rust toolchain:

git clone https://github.com/yongkyuns/noon.git
cd noon
cargo run -p noon-native --example ordinary_affine_play

About Noon

Project history

Noon started as a small prototype. Recent development has included a redesign with AI coding agents.

Manim compatibility

Manim Community Edition is the reference for the Python APIs and visual behavior that Noon supports. The implementation reference describes coverage and limitations by host.

Current status

APIs are still changing. Playback and feature support differ between native and browser hosts. Some callback-driven and interactive scenes have replay restrictions.
